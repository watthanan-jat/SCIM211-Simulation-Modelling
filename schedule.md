## Lab and Project Pathway

The seven assessed labs develop one continuing Coffee Shop Simulation Project:

1. Map the real system and build a first simulation.
2. Generate and investigate pseudo-random numbers.
3. Transform random numbers into realistic model inputs.
4. Use Monte Carlo experiments to compare profit and promotion decisions.
5. Build a discrete-event coffee-shop queue.
6. Model customer loyalty using Markov chains.
7. Validate the model and develop a defensible recommendation.

In Week 16, groups apply the model they have built to an assigned Project Challenge.
