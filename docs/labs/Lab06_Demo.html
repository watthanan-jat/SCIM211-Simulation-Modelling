Theory 1: The Markov property (Chapter 8, Section 8.3)¶

Let $X_n=0$ if day $n$ is dry and $X_n=1$ if it is wet. The sequence $X_0,X_1,X_2,\dots$ is a Markov chain if

$$ \mathbb P(X_{n+1}=j\mid X_n=i,\ X_{n-1},\dots,X_0)=\mathbb P(X_{n+1}=j\mid X_n=i)=p_{ij}. $$

Given today, the past adds nothing for predicting tomorrow. The $p_{ij}$ form the transition matrix $P$: row $i$ is "from $i$", column $j$ is "to $j$".

This is a claim about the model, not about reality. Real weather has a longer memory; if that matters, a better model enlarges the state (for example "wet for two days in a row" as its own state).

Question: Is each process plausibly Markov with the state given?

  1. Tomorrow's weather, with state = today's weather.
  2. Your final exam mark, with state = your last quiz mark only.
  3. The number of customers in a shop at the end of each minute, with random arrivals and service completions (Chapter 8, Section 8.8).

Demo 1: The Dry/Wet transition matrix¶

Chapter 8 assumes $\mathbb P(\text{Dry tomorrow}\mid\text{Dry today})=0.7$ and $\mathbb P(\text{Wet tomorrow}\mid\text{Wet today})=0.8$. Each row must be a probability distribution, so the missing entries are $0.3$ and $0.2$.

From / To Dry Wet
Dry 0.7 0.3
Wet 0.2 0.8

A valid transition matrix is square, and every row is a probability distribution:

$$ 0\le p_{ij}\le1\quad\text{for all } i,j,\qquad \sum_j p_{ij}=1\quad\text{for every row } i . $$

These are two separate conditions: a row can sum to 1 and still contain a negative number.

Theory 2: One step from one uniform number (Chapter 8, Section 8.4.3)¶

From state $i$, draw $U\sim\mathrm{Uniform}(0,1)$ and split $[0,1]$ into pieces whose lengths are the probabilities in row $i$. With two states there is one cut point, $p_{i0}$:

  • if $U\le p_{i0}$, tomorrow is Dry (state 0);
  • otherwise tomorrow is Wet (state 1).
Today cut point $p_{i0}$ Dry if Wet if
Dry 0.7 $U\le0.7$ $U>0.7$
Wet 0.2 $U\le0.2$ $U>0.2$

This is the discrete inverse-transform method of Lab 3: each piece has length equal to its probability.

def next_day(matrix, today, u):
    # Next state of a TWO-state chain: Dry (0) if u <= p_{today,0}, otherwise Wet (1).
    if u <= matrix[today, 0]:
        return 0
    else:
        return 1

Theory 3: The distribution of a chain (Chapter 8, Section 8.5)¶

A forecaster wants probabilities, not one story. Write the distribution on day $n$ as a row vector $\pi_n=(\mathbb P(X_n=\text{Dry}),\ \mathbb P(X_n=\text{Wet}))$. Conditioning on today's state,

$$ \pi_{n+1}=\pi_nP,\qquad\text{so}\qquad\pi_n=\pi_0P^n , $$

and $(P^n)_{ij}=\mathbb P(X_n=j\mid X_0=i)$. Chapter 8's two-step example:

$$ P^2=\begin{pmatrix}0.7&0.3\\0.2&0.8\end{pmatrix}\begin{pmatrix}0.7&0.3\\0.2&0.8\end{pmatrix}=\begin{pmatrix}0.55&0.45\\0.30&0.70\end{pmatrix}, \qquad \mathbb P(X_2=\text{Dry}\mid X_0=\text{Wet})=0.30 . $$

Once $\pi_0$ and $P$ are fixed, $\pi_n$ is not random. Simulating $m$ independent paths and counting states reproduces $\pi_0P^n$ up to sampling error, about $\sqrt{p(1-p)/m}$.

Theory 4: The stationary distribution (Chapter 8, Section 8.7)¶

A probability vector $\pi$ is stationary if

$$ \pi=\pi P,\qquad \sum_j\pi_j=1 . $$

If today's distribution is $\pi$, tomorrow's is also $\pi$.

Chapter 8's example, by hand. With $\pi=(\pi_D,\pi_W)$, the first component of $\pi=\pi P$ gives

$$ \pi_D=0.7\pi_D+0.2\pi_W\ \Longrightarrow\ 0.3\pi_D=0.2\pi_W . $$

The second component gives $\pi_W=0.3\pi_D+0.8\pi_W$, that is $0.2\pi_W=0.3\pi_D$: the same equation. One equation of $\pi=\pi P$ is always redundant, because every row of $P$ sums to 1. The condition $\pi_D+\pi_W=1$ is what pins down the answer:

$$ \pi_D=\tfrac25=0.4,\qquad \pi_W=\tfrac35=0.6 . $$

In the long run about 60% of days are wet. (Read $0.3\pi_D=0.2\pi_W$ as a balance: in the long run, the flow from Dry to Wet equals the flow from Wet to Dry.)

Ergodic theorem for finite chains. If the chain is irreducible (every state can reach every other) and aperiodic (for example some $p_{ii}>0$), then

  1. there is exactly one stationary distribution $\pi$;
  2. $(P^n)_{ij}\to\pi_j$ for every starting state $i$: the rows of $P^n$ become identical;
  3. the fraction of time one long path spends in state $j$ converges to $\pi_j$.

Both conditions hold here: Dry and Wet reach each other in one step, and $p_{DD}>0$.

Theory 5: Dependence and warm-up (Chapter 8, Section 8.8)¶

Days inside one run are dependent. In Labs 4 and 5 each replication was independent, so $\bar X\pm1.96\,s/\sqrt n$ worked. Inside one run of the weather chain, today strongly predicts tomorrow: wet days come in clumps. For a stationary sequence with variance $\sigma^2$ and lag-$k$ correlations $\rho_k$ (Chapter 9),

$$ \operatorname{Var}(\bar X_N)=\frac{\sigma^2}{N}\left[1+2\sum_{k=1}^{N-1}\Bigl(1-\frac kN\Bigr)\rho_k\right]. $$

With positive correlations the bracket is larger than 1, so the naive $s/\sqrt N$ from one run is too small.

Runs remember their start. Starting Dry, $\mathbb P(X_n=\text{Wet})=0.6(1-0.5^n)$ reaches 0.6 only gradually, so early days over-represent Dry. Discarding the first part of each run is a warm-up.

The honest fix. Run independent replications, take one number per run, and use the spread across runs.

Demo 7: A strong interpretation¶

Under the wetter-climate matrix, the long-run share of wet days would rise from 60% to about 80%, and most of the change appears within a week of the new pattern starting. The larger single driver is that wet spells last longer. These figures are exact consequences of the assumed matrix, not forecasts: the matrix should be estimated from observed day-to-day transitions before it is used for planning. For any uncertainty statement based on simulating one long weather record, consecutive days are dependent, so the standard error must come from independent runs, not from $s/\sqrt N$ within one run.

A strong recommendation connects: what the model predicts, with numbers; how quickly the effect appears; which assumption drives it; whether the result is exact or simulated, and how its uncertainty was measured; what evidence is needed next.

Final theory map¶

Markov property: $\mathbb P(X_{n+1}=j\mid X_n=i,\text{past})=p_{ij}$.

Valid matrix: square, $0\le p_{ij}\le1$, and every row sums to 1.

One step: with two states, Dry if $U\le p_{i0}$, otherwise Wet; in general, the first cut point of the cumulative row at or above $U$.

Distribution: $\pi_{n+1}=\pi_nP$, so $\pi_n=\pi_0P^n$; $(P^n)_{ij}=\mathbb P(X_n=j\mid X_0=i)$.

Stationary: $\pi=\pi P$, $\sum\pi_j=1$ (one equation of $\pi=\pi P$ is redundant); for Dry/Wet, $\pi=(0.4,0.6)$. For an irreducible, aperiodic finite chain the rows of $P^n\to\pi$ and time fractions $\to\pi$.

Output analysis: days inside one run are dependent ($s/\sqrt N$ is too small); runs remember their start (warm-up); use independent replications.

This … … is not this
one path the distribution $\pi_0P^n$
rows summing to 1 a valid matrix (entries must also be in $[0,1]$)
a long path's time fractions (random) the stationary distribution (exact)
$s/\sqrt N$ from one run the real uncertainty of the run average
an exact scenario calculation a simulation estimate
a scenario matrix evidence about the real system

Common errors¶

  • Checking only the row sums, not the bounds or the shape.
  • Comparing a sum of floats with == 1.
  • Using the Dry row's cut point after moving to Wet.
  • Creating a new generator inside a path function, which repeats the same path every time.
  • Multiplying in the wrong order (P @ pi0 instead of pi0 @ P).
  • Solving $\pi=\pi P$ without the condition $\sum\pi_j=1$.
  • Treating the days inside one run as independent observations.
  • Calling a scenario matrix "evidence".
